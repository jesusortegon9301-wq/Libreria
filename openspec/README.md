# Flujo OpenSpec/OPSX

1. **`/opsx:explorar`**: inspeccionar el repositorio y recopilar evidencia sin modificar archivos.
2. **`/opsx:proponer`**: preparar `proposal.md`, `specs/`, `design.md` y `tasks.md`.
3. **Revisión**: el usuario evalúa y aprueba el alcance.
4. **`/opsx:aplicar`**: aplicar exclusivamente tareas aprobadas.
5. **`/opsx:verificar`**: contrastar requisitos, implementación, pruebas y documentación.

Los nombres exactos dependen de la instalación. No simular comandos ni reportar pruebas no ejecutadas. Para documentación, no modificar producción ni esquema de base de datos. Cada cambio debe residir en `openspec/changes/` con el formato exigido por la versión instalada.
